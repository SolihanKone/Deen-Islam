Privacy policy file to host on HTTPS:
  legal/privacy_policy.html
  (same page also at docs/index.html for GitHub Pages)

How to get a public HTTPS URL (required by both stores):
  1. Create a GitHub repository for this project (or any static host).
  2. In the repo, Settings → Pages → Source: Deploy from a branch → /docs.
  3. The URL will look like:
     https://YOUR_GITHUB_USERNAME.github.io/YOUR_REPO_NAME/
  4. Paste that URL in App Store Connect (App Privacy) and Play Console (Store listing + Data safety).
